## 공포 게임 심층 분석의 조사 자료
구성 요소·심리와 플레이어 행동·경험 흐름의 세 분석 문서는 아래 자료 번호를 함께 쓴다. 확인일은 2026-10-30이다. 문서의 구분과 설명용 가정은 정리자의 분석이다.
개발자 글·인터뷰·공식 설명서·연구 논문을 근거로 삼았다. 직접 플레이나 영상 관찰은 하지 않았다. 발표 자료는 슬라이드를 읽었으며 발표 영상을 시청하지 않았다.
11번은 공개 초록과 요약만 확인했다. 나머지는 본문 또는 관련 슬라이드를 확인했다. 개발자 회고는 설계 의도와 관찰의 근거로 쓰며, 플레이어 전체의 반응을 입증하는 실험 결과로 취급하지 않는다.
