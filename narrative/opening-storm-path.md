# 오프닝 — 어둠 속의 폭우, 길 찾기

## 요소

- 날씨: 폭우
- 어둡고 사방에 나무만 있음
- 나무 사이로 사람의 실루엣
- 실루엣 뒤편으로 절의 불빛

## 경험

| 강도 | 내용 |
|------|------|
| 공포 3 | 시야가 확보되지 않고 어두운 숲속 |
| 공포 3 | 헉헉대는 숨소리와 세찬 빗소리 |
| 공포 3 | 나무 사이로 빠르게 지나가는 검은 실루엣 (사운드로 점프 스케어) |
| 완화 | 희미하게 보이는 빛 |
| 공포 1 | 문을 지나갈 때 사천왕의 무서운 얼굴 |
| 완화 | 스님의 온화한 태도, 귀여운 강아지 |

## 의도

- 어두움과 소리로 공포 분위기를 조성한다.
- 대사 없이 길을 찾도록 해서 막막한 느낌이 들게 한다.
