# Narrative — 내러티브 허브

세계관·스토리·캐릭터·오프닝 등 **설정·톤·용어** 정본. 메카닉·수치·구현은 `planning/`·코드·활성 `Tasks/`.

현재 주인공은 **피해자의 유가족**이며 기자를 가장해 절을 찾는다. 가해자가 편안하게 떠났다는 소문을 확인한다. 사건·엔딩 문서(`story/`)에는 이전 기자 설정이 남아 있으며, 새 주인공의 사건과 결말은 재구성 중이다. 공간과 오프닝 연출은 `environment/`, 인물은 `characters/`에 둔다.

## 추가 예정

- 세계 규칙·용어·톤
- 캐릭터의 이름·소속 등 세부 설정(PD 확정 후)

체험·놀기 규칙: `planning/content/` 하위 문서.
