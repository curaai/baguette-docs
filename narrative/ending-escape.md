# 엔딩 분기 — 탈출

**기자로서 할 일**을 택한 결말 — 도주, 살아남기, 그리고 **특종·뉴스**로 현실에 돌아가는 잔향.

## 요소

- 날씨: 폭우 → 흐림
- 대웅전에 들어감
- 바닥에 흙먼지, 비도 들이침, 신문 흩어져 있음, 신문을 묶어놨던 빨간 노끈이 떨어져 있음
- 노끈을 획득한 뒤 스님에게 다가감
- 스님이 이걸로는 안 될 것 같다고 함
- 엄청나게 문이 덜컹거림
- 스님이 나보고 먼저 이곳을 떠나라고 함
- 화면 주변이 어두워지면서(탑 돌 때와 비슷) 문 밖으로 탈출
- 화면 전환 후 엔딩 — **원룸** 방에서 TV를 보고 있음
- 옆에 있는 리모콘과 상호작용하여 채널 돌림
- ○○산에 대한 이야기가 **뉴스**로 나오며 끝 — 살아남은 기자의 시선으로 특종의 그림자가 스친다

## 의도

- 분기의 의미: **기자 본분** — 살아남아 소식을 밖으로 가져간다. 봉인·연대보다 도주·특종·뉴스.
- 원룸·TV·뉴스는 유지·강화한다. ‘등산객이 집에 돌아왔다’가 아니라 **취재가 현실이 된** 여운.
- 흐림·불안 잔향. 스님·절의 운명은 뉴스 너머로만 암시된다(확정 대사는 writer).
- ○○산 정식 명칭은 PD 미결 ([narrative-summary](narrative-summary.md)).
