# 입구 배경 — 참배로·절 입구

산길에서 절 입구(사천왕·문)까지. 오프닝 [[../opening-storm-path|폭우 속 길 찾기]]가 일어나는 구간.

## 범위

- 절로 이어지는 **참배로(산길, 50~100m)**
- **절 입구** — 문, 사천왕상
- 입구 직전까지의 **주변 산·숲** (담장 밖, 아래 사면)

절터(담장 안)는 `(temp)-temple-grounds.md` 및 하위 절터 문서를 따른다.

## 구성 요소

| 요소 | 역할 |
|------|------|
| 참배로(산길) | 유일한 진입 축, 구불구불 |
| 석등·이정 돌 | 표식, 방향 안내 |
| 주변 활엽수·수관 | 고립감, 시야 제한 |
| 안개층 | 깊이·고립 연출 |
| 절 입구·문 | 산길 종료, 절터로의 전환 |
| 사천왕상 | 입구 통과 시 짧은 공포 비트(공포 1) |

## 배치

```text
        숲 · 안개 · 수관
              │
    석등 ─ 표식 ─ 이정 돌
         ╲    │    ╱
          ╲   │   ╱   (50~100m, 구불구불)
           ╲  │  ╱
            ╲ │ ╱
         [ 절 입구 · 사천왕 ]
              │
         ──→ 절터 ((temp)-temple-grounds)
```

## 공간 규칙

- 참배로는 입구까지 **약 50~100m**, **구불구불**한 **단일 진입 축**이다.
- 진행 톤은 **표식을 따라 천천히**다. 커브마다 다음 표식이 보이며 길을 잇고, 절터는 마지막에 열린다.
- 방향은 **표식으로만** 잇는다. 프랍 밀도는 낮게 두고 주연출은 **길 읽기**와 **안개 속 고립**이다.
- 산길 프랍은 **참배로형**(석등, 이정 돌)만 쓴다. 절터(담장·석축·마당) 프랍과 **종류·역할이 겹치지 않게** 구분한다.
- 산길은 절터보다 **수관·안개가 더 가깝게** 읽히게 한다.
- **입구를 넘어 마당에 들어서면** 하늘이 주 개방면이 되게 한다 — 절터 외부(`temple-exterior.md`)와의 전환점이다.
- 아이디어·기각 후보: [[planning/references/temple-approach-path-ideas|절 접근 참배로 아이디어]]

## 비주얼

- 시야가 확보되지 않는 **어두운 숲속**. 오프닝은 폭우·헉헉이는 숨·세찬 빗소리가 주 연출.
- 나무 사이 **검은 실루엣**은 보이기보다 **사운드 점프 스케어**로 처리한다.
- **희미한 빛**(절 불빛)이 먼 목표로 작동한다.
- 숲·수관 명도는 길 바닥보다 한 단계 낮추고, **산길 끝·입구 뒤**에만 옅은 냉색 안개층을 둔다.
- 밤·폭우에는 나무를 어두운 실루엣으로 감추고, 손전등이 **길과 표식 일부**만 드러낸다.
- 젖은 표면 반사는 재질을 읽을 정도만. 손전등 정면 과노출은 피한다.
- 안개·노이즈·비네팅은 **진행 경로 가독성**을 해치지 않는 범위에서만 쓴다.

## 배경 레이어

### 근경 — 길과 표식

- 석등, 이정 돌, 젖은 암반·낙엽, 길가 덩굴·고사목.
- 플레이어 시선 높이에서 **길의 연속성**이 가장 먼저 읽혀야 한다.

### 중경 — 숲과 수관

- 곧게 솟은 활엽수, 낮은 수관 군집. 숲 전체를 채우기보다 **안개 속 나무줄기**로 깊이를 만든다.
- 수관이 길 위를 부분적으로 덮어 **답답함**을 유지한다.

### 원경 — 능선과 안개

- 능선 실루엣 1~2겹, 저밀도 수관. 탐험 공간이 아니라 **고립·방향 상실**용 배경.
- 폭우·밤에는 능선을 안개에 숨긴다.
