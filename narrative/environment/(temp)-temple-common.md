# 절 공통

담장 안 **절터 전체**에 공통으로 적용하는 공간 규칙·장식 문법·비주얼. 구역별 묘사는 외부·내부·건물 문서를 따른다.

## 범위

- 절 근처 **담장·석축**으로 둘러싼 구역
- **중앙 마당**, **대웅전**, **요사채**, **명부전**
- 돌길·돌계단, 요사채 뒤 **화장실·창고**
- 마당 중앙 **석탑**, 명부전 앞 **우물**(미사용)

진입 전 산길·절 입구는 `approach-entrance.md` 범위다.

## 구성 요소

| 공간 | 설명 |
|------|------|
| 중앙 마당 | 십자형 돌길, 나머지 모래 바닥, 구석 수돗가, 중앙 석탑 |
| 대웅전 | 불상을 모시는 주요 건물, 마당보다 높은 단 |
| 요사채 | 스님과 플레이어 숙소, 마당과 같은 높이 |
| 명부전 | 위패 봉안당, 마당보다 높은 단, 뒤쪽 가파른 비탈 |
| 화장실·창고 | 요사채 뒤, 눈에 덜 띄는 위치 |
| 담장·석축 | 플레이·시야 경계 1순위 |

## 배치

```text
                  가파른 산비탈

             [ 명부전 ]   [ 대웅전 ]
                    돌계단

         [ 요사채 ] ── [ 중앙 마당 · 석탑 ]
              │                │
      [ 화장실·창고 ]      [ 절 입구 ]
                               │
              ← approach-entrance (참배로)
```

## 공간 규칙

- 절은 산 중턱의 주변보다 **높은 지대**에 두어, 아래 숲보다 마당과 본당이 한 단 위에 있게 한다.
- 담장·석축으로 절터를 구획하고, **담장이 플레이·시야 경계의 1순위**가 되게 한다.
- 절 **뒤쪽**은 가파른 비탈로 이동 범위를 제한하되, 수관으로 위를 덮지 않는다.
- 절 **양옆·아래 사면**에 나무를 두어 둘레만 숲이 보이게 하고, 절터 자체는 숲 속이 아니게 한다.
- 절 **앞쪽**은 참배로와 입구만 열어 진입 방향을 명확하게 보여준다.
- 대웅전·명부전은 마당보다 높은 곳에 두고 **돌계단**으로 연결한다.
- 요사채는 중앙 마당 옆 **같은 높이**에 둔다.
- 명부전 뒤쪽은 가장 가파르게 구성해 **심리적 압박**과 진행 방향을 함께 만들되, 머리 위 수관은 비운다.

## 장식 문법 — 겉옷과 속

호러 스타일라이즈 톤. 한국 사찰은 알아보이되, **공포가 먼저** 읽히게 한다.

| 겉 (낮·일상) | 속 (카메라·밤) |
|------|------|
| 익숙한 사찰 소품, 쓸고 닦을 수 있는 표면 | 같은 소품이 **각도·시간에 따라 어긋남** |
| 밝고 건조한 질감, 제한적 단청 포인트 | 짙은 청록·검은 갈색이 **국소적으로 번짐** |
| 손님에게 보여도 되는 정돈 | 기자만 보는 **틀어진 디테일** |

유저는 낮에 평범한 절을 학습하고, 밤·카메라에서 **같은 공간의 다른 면**을 깨닫는다.

```text
낮: 건조, 중성광, 소품이 제자리
  ↓
밤: 같은 배치, 질감만 젖고 어두워짐 + 손전등이 비추는 면만 선명
  ↓
카메라: 겉 레이어 유지 + 속 레이어만 겹침 (발자국, 실루엣, 어긋난 장식)
```

## 비주얼

- 기본 팔레트: 짙은 청록, 검은 갈색, 회색 화강암. 황토·바랜 단청은 **제한적 포인트**로만 쓴다.
- 마당·대웅전 시야의 **주 개방면은 하늘**이다. 밤·폭우에도 덮인 숲이 아니라 **열린 천공**과 먼 능선 실루엣으로 읽히게 한다.
- 아래 숲·먼 능선 명도는 건물보다 한 단계 낮춘다.
- 밤·폭우에는 사면 나무·능선을 어두운 실루엣으로 감추고, **손전등·국소 조명**이 공간 일부만 드러낸다.
- **명부전** 구역은 마당·요사채보다 어둡고 낡게 읽히게 한다 — 온화한 일상 공간과의 대비.
- 새벽에는 안개·청록을 줄이고 중성광을 늘려 비가 그친 변화를 보여주되 공포의 잔향은 남긴다.
- 안개·노이즈·비네팅은 실루엣·진행 경로·위협 **가독성을 해치지 않는** 범위에서만 쓴다.

## 배경 레이어

### 근경 — 플레이 경계

- 마당 둘레 **담장·석축** 단, 배수로.
- 흙 절개지·젖은 암반 — 지대 높이 표현.
- 나무뿌리·덩굴·고사목·큰 양치류 — 담장 밖·비탈 쪽, 경계 보조.
- 명부전 뒤 **가파른 비탈** — 심리적 압박, 머리 위 수관 없음.

### 중경 — 사면의 숲

- 절에서 10~25m 떨어진 **아래·옆 사면**에 활엽수·소수 소나무 군집.
- 절터 상공(마당·본당 머리 위)은 **수관을 비워** 하늘이 탁 트이게 한다.
- 안개 속 나무줄기·낮은 수관 군집으로 깊이 표현.

### 원경 — 산 능선

- 산 능선 2~3겹, 저밀도 수관 실루엣.
- 밤·폭우에는 능선을 안개에 숨기고, 새벽에는 안개가 걷히며 윤곽이 드러난다.
- 탐험 공간이 아니라 **열린 고지 고립·전망**용 배경.
