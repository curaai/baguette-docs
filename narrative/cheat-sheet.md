# 게임 내러티브 치트 시트 — 프로젝트 적용

**Game Narrative Design — Quick Reference**

현재 내러티브 문서에서 확인되는 설정을 치트시트 항목에 연결한다. 확정되지 않은 캐릭터 과거나 구조 선택은 새로 만들지 않고 **미정**으로 표시한다. 세부 플레이 규칙과 조작은 [기획 문서](../planning/)를 기준으로 한다.

## 1. 내러티브 핵심 공식

> **게임 내러티브 = 플레이어의 목표 + 행동 + 갈등 + 결과 + 의미**

| 요소 | 핵심 질문 | 현재 프로젝트 적용 |
|---|---|---|
| **Fantasy** | 플레이어는 어떤 존재가 되는가? | 특종을 쫓는 **기자**가 되어, 등산객으로 위장해 산속 절에 머물며 주변을 조사한다. |
| **Motivation** | 왜 행동해야 하는가? | 흉악범 유가족과 부자들이 ○○사를 수상하게 찾는다는 제보를 확인하고 특종을 잡으려 한다. |
| **Conflict** | 무엇이 목표를 방해하는가? | 기자라는 정체를 감춘 채 조사해야 한다. 절의 비밀과 명부전의 금기, 위패가 부서진 뒤 깨어나는 원혼이 위험을 키운다. |
| **Agency** | 플레이어가 무엇을 바꿀 수 있는가? | 클라이맥스에서 원혼을 **진정·봉인**할지, 기자 본분을 택해 **탈출·특종**을 노릴지 결정한다. |
| **Consequence** | 행동이 세계에 어떤 영향을 주는가? | 봉인하면 스님과 함께 사태를 진정시키고 절을 다시 찾는다. 탈출하면 기자는 살아서 돌아가고 절의 사건은 뉴스의 형태로 남는다. |
| **Payoff** | 어떤 감정과 의미를 남기는가? | 봉인은 평화와 빚의 여운, 탈출은 생존과 특종 뒤에 남는 불안한 잔향을 준다. |

**한 줄 서사:** 제보를 쫓아 산속 절에 들어온 기자가 사흘 동안 단서를 모으고, 금지된 명부전에서 위패를 부수어 원혼을 깨운 뒤 봉인과 탈출 사이에서 선택한다.

## 2. 내러티브 구조

| 구조 | 일반적인 활용 | 현재 프로젝트 적용 |
|---|---|---|
| **3막 구조** | 메인 스토리, 캠페인 | 제보와 절 도착 → 사흘간 조사와 공포 누적 → 명부전의 위기와 결말 분기로 요약할 수 있다. 정식 3막 구분은 문서에서 확정하지 않았다. |
| **Hero's Journey** | 영웅 성장 서사 | 기자의 성장·귀환 아크를 적용했다는 정본은 없다. |
| **Kishōtenketsu (기승전결)** | 탐험·발견 중심 서사 | 탐색과 발견이 주요 경험이지만, 기승전결 구조를 정식 채택했다는 기록은 없다. |
| **Branching Narrative** | 선택과 분기 | 클라이맥스에서 봉인 또는 탈출을 택하며, 각기 다른 엔딩으로 이어진다. |
| **Emergent Narrative** | 시스템에서 발생하는 이야기 | 시스템에서 이야기가 발생하는 구조는 내러티브 문서에서 확인되지 않는다. |
| **Environmental Storytelling** | 공간과 오브젝트로 전달하는 이야기 | 삐져나온 석탑 돌, 포장된 뉴스 조각과 신문 더미, 명부전의 위패와 공간 흔적으로 단서를 쌓는다. |
| **Systemic Narrative** | 반복 가능한 규칙과 시스템을 통한 서사 | 반복 규칙이나 시스템 상태가 만드는 서사는 내러티브 문서에서 확인되지 않는다. 관련 플레이 규칙은 기획 문서를 확인한다. |

## 3. 퀘스트 내러티브

> **Hook → Goal → Obstacle → Choice → Payoff**  
> 흥미 유발 → 목표 제시 → 장애물 → 선택 → 보상과 변화

| 단계 | 현재 프로젝트의 서사 비트 |
|---|---|
| **Hook** | 수상한 절 방문에 관한 제보를 받고 산에 오른다. 길을 잃고 발목을 다친 채 폭우 속에서 절을 발견한다. |
| **Goal** | 등산객으로 위장해 절에 머물며 제보를 확인하고 특종을 잡는다. |
| **Obstacle** | 정체를 감추며 조사해야 하고, 단서를 따라갈수록 명부전의 비밀과 원혼의 위협에 가까워진다. |
| **Choice** | 금지된 명부전에 들어가고, 위패가 부서진 뒤에는 원혼을 봉인할지 탈출할지 결정한다. |
| **Payoff** | 봉인 엔딩은 진정·연대와 재방문의 여운을, 탈출 엔딩은 생존·뉴스와 불안한 잔향을 남긴다. |

좋은 퀘스트는 무엇을 할지뿐 아니라 **왜 해야 하는지**도 제공한다. 이 프로젝트에서는 특종을 쫓는 기자의 동기가 조사와 위험 감수의 이유가 된다.

## 4. 플레이어 에이전시의 4단계

1. **Expression — 표현**: 3일차 스님과의 대화에서 죄가 있는지 묻는 말에 예/아니오로 답한다. 외형이나 대사 표현 선택의 범위는 **미정**이다.
2. **Tactical — 전술**: 공간을 살피고 단서를 확인하는 행동은 서사에 등장한다. 단서 조사와 위기 해결 방법의 구체적 선택 범위는 기획 문서를 따른다.
3. **Narrative — 서사**: 클라이맥스에서 봉인 또는 탈출을 골라 결말을 바꾼다.
4. **Systemic — 시스템**: 플레이어 선택이 반복 가능한 세계 규칙이나 시스템 상태를 바꾸는지는 내러티브 문서에서 확인되지 않는다.

현재 문서에서 명확히 설정된 주요 선택은 **봉인 / 탈출** 분기다. 선택지의 개수보다 결과가 플레이어에게 체감되는 정도가 중요하다.

## 5. 내러티브 디자인 체크리스트

| 질문 | 상태 | 현재 문서에서 확인되는 내용 |
|---|---|---|
| 플레이어의 역할과 목표가 명확한가? | **정리됨** | 기자가 등산객으로 위장해 제보를 확인하고 특종을 쫓는다. |
| 게임플레이와 서사가 같은 방향을 향하는가? | **부분 정리** | 잡일과 은밀한 조사를 연결하는 의도는 있다. 세부 플레이 정합성은 기획 문서 확인이 필요하다. |
| 갈등이 플레이어 행동을 유도하는가? | **정리됨** | 제보와 특종 욕심이 조사와 명부전 진입의 동기가 된다. |
| 선택에 의미 있는 피드백이 있는가? | **부분 정리** | 봉인·탈출의 주제와 엔딩은 다르다. 세부 결과와 피드백은 추가 정리가 필요하다. |
| 캐릭터의 행동에 일관된 동기가 있는가? | **부분 정리** | 기자의 특종 욕심과 스님의 영혼 구원 신념은 정리돼 있다. 과거와 일부 선택 동기는 미정이다. |
| 세계관 정보가 플레이 중 자연스럽게 전달되는가? | **정리됨** | 공간 흔적, 뉴스 조각, 신문, 대화와 위패를 통해 단서를 누적한다. |
| 주요 사건에 감정적 보상이 존재하는가? | **부분 정리** | 봉인의 평화와 탈출의 불안한 잔향은 제시돼 있다. 연출 세부는 보완 여지가 있다. |
| 반복 플레이와 스킵 상황에서도 이해 가능한가? | **미정** | 반복·스킵 상황을 고려한 정보 전달 방식은 정본에서 확인되지 않는다. |

## 6. 실무에서 기억할 원칙

- **Show, Don't Tell**: 석탑의 어긋난 돌, 신문과 뉴스, 위패의 이름처럼 공간과 오브젝트로 단서를 발견하게 한다.
- **Gameplay First**: 마당 일과 청소가 탐색과 조사에 자연스럽게 이어지게 한다. 불필요한 동선과 상호작용은 지양한다.
- **Narrative Consistency**: 겉은 등산객이고 속은 기자라는 위장, 평소 온화하다 명부전과 관련해 균열이 드러나는 스님, 악몽과 클라이맥스의 검은 존재를 일관되게 유지한다.
- **Player-Centric**: 정보를 설명으로 한꺼번에 전달하기보다, 플레이어가 공간을 살피고 단서를 알아차리는 흐름을 우선한다.
- **Setup & Payoff**: 첫날 석탑 돌, 둘째 날 뉴스와 신문, 셋째 날 스님의 말과 명부전 위패를 이어 원혼 각성으로 보상한다. 엔딩은 봉인 또는 탈출 선택의 정서를 회수한다.
