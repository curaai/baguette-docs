# 2일차

## 낮 — 간단한 일 도와주기

### 요소

- 날씨: 폭우
- 스님과 인사
- 명부전 쪽 계단을 쓴다
- 계단 근처에 잘 포장된 흉악범 뉴스 조각 발견 — **카메라로 남기고 싶은** 단서이나, 스님 앞에서는 대놓고 찍지 않는다(은밀 조사)
- 아이템과 상호작용하는 순간 스님이 나타나며, 뭔가 비밀이 있는 듯 대웅전 가서 바닥을 닦아달라고 함
- 대웅전 들어갈 때 위압적인 부처님 얼굴
- 들어가서 바닥 닦기
- 대웅전 구석에 쌓여 있는 비슷한 내용의 신문 더미 — 기자의 눈으로 읽어 단서를 쌓음

### 경험

| 강도 | 내용 |
|------|------|
| 완화 | 스님과 인사 |
| 완화 | 계단 청소 |
| 공포 2 | 갑자기 나타나는 스님 (사운드로 점프 스케어) |
| 공포 2 | 대웅전의 커다란 부처님에 압도 |
| 완화 | 바닥 닦기 — ‘마음이 편안해진다…’ |
| 공포 1 | 구석에 쌓여 있는 신문 더미 발견 |

### 의도

- 자잘한 공포와 의심, 불안한 감정이 쌓이게 한다.
- **신문·뉴스 단서**와 **카메라 단서**가 같은 조사 축으로 누적된다. 메카닉 본문은 `planning/` 정본.
- 스님 앞에서는 수상하지 않게 — 카메라는 취미로 둘러대는 **위장**이 유지된다.
- (카메라로만 보이는 삿된 흔적이 있다면) 직접 발견형으로 짧게 스치되, 대낮에 과하지 않게.

## 밤 — 개 짖는 소리로 깸, 개와 친해지기

### 요소

- 날씨: 비
- 검정 화면 + 풀벌레 소리 → 갑작스러운 개 짖는 소리, 밖으로 나가본다
- 개가 무언가 찢어진 인형을 물고 문 앞에서 짖고 있다
- 불길한 느낌이 드는 인형
- 개를 달래주고 다시 방에 들어감
- 검정 화면 + 아무 소리 없음, 이어서 **무서운 꿈(악몽)**

### 경험

| 강도 | 내용 |
|------|------|
| 완화 | 따뜻한 느낌의 방 안으로 들어옴 |
| 완화 | 검정 화면 + 풀벌레 소리 |
| 공포 2 | 개 짖는 소리 |
| 공포 2 | 불길한 느낌이 드는 인형 |
| 완화 | 그와는 반대로 해맑은 강아지 |
| 완화 | 귀여운 강아지와 놀아주고 |
| 완화 | 다시 방 안으로 들어옴 |
| 공포 5 | 풀벌레 소리 등 환경음이 사라진 적막감 |
| 공포 5 | 무서운 꿈 — 검고 붉은 악몽 |

### 의도

- 환경음이 완전히 사라진 적막감으로 무언가 바뀌었음을 암시해야 한다.
- 꿈 = **검고 붉은 악몽에서 벗어나기**. 원혼들의 소리가 들리는(안 들리는?) 쪽으로 가야 한다 — **소리로 길찾기**.
- 꿈에서 뭔가에 쫓기는 연출 — 좌·우 문으로 계속 선택하며 들어가는 조작(체험 세부는 `planning/`)
- 마지막은 무섭게 덜컹거리는 명부전의 문을 열면서 꿈에서 깸
- 악몽은 3일 밤 명부전·원혼과 **같은 공포 언어**로 정렬한다.
