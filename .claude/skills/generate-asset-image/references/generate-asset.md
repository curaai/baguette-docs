# 에셋 이미지 생성 참고

프로젝트에서 `/generate-asset`를 요청하면 다음 실행 기준을 따른다.

1. 서사 문서를 읽고 가장 가까운 기존 에셋·참고 이미지를 확인한다.
2. 제작 지침에서 에셋 개수, 생성 도구(ImageGen), 스타일, 카메라, 배치, 조명을 확인한다. 미정인 선택은 프로젝트 기본값을 유지한다.
3. 참고 이미지를 첨부해 생성한다. 멀티뷰는 2×2 배치와 정면 / 왼쪽 / 오른쪽 / 뒷면 순서(`front / left / right / behind`)를 고정한다.
4. 원본 이미지를 저장하고, 요청된 경우 표준 접미사를 사용해 네 구역을 정확히 분할한 PNG로 출력한다.
5. 출력물을 확인하고 경로와 짧은 파일 목록을 전달한다.

대웅전 프로젝트의 기본 스타일은 저채도 오래된 목재, 먹회색 기와, 절제된 풍화, 중앙 정렬된 대칭 구도, 흰 배경이다.
