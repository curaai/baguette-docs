# 에셋 이미지 생성

일관된 시각적 정체성을 유지하며 제작에 사용할 래스터 에셋 이미지를 만든다. 프로젝트 제작 지침과 제공된 참고 이미지를 기준으로 삼는다. 생성에는 ImageGen을 사용하고, 정확한 분할 출력에는 로컬 이미지 처리를 사용한다.

## 작업 순서

1. 관련 서사 문서나 에셋 제작 지침을 읽고 배경 원화·단일 에셋·에셋 멀티뷰 중 요청 유형을 구분한다. 에셋 이름, 필요한 변형, 배경, 카메라, 배치, 출력 폴더를 확인한다. 지정되지 않은 형상을 임의로 만들지 않는다.
2. 제공된 참고 이미지를 직접 확인한다. 대웅전 템플릿이 지정된 작업이면 `C:\Users\admin\.codex\skills\artifact-template-daeungjeon\artifact-template.json`을 읽고 보관된 참고 이미지를 사용한다.
3. 생성 전에 프로젝트 제작 지침과 참고 이미지로 시각 방향을 고정한다. 배경 원화는 아래 기본 보드 구성을 적용한다. 사찰 단일 에셋은 사용자가 명시적으로 변경하지 않으면 저채도 짙은 목재, 먹회색 기와, 절제된 풍화, 중앙 정렬된 정투영·정면 구도, 깨끗한 흰 배경, 설명 표기 없음을 유지한다.
4. 래스터 이미지 생성·편집에는 내장 ImageGen 도구를 사용한다. 배경 원화는 quarter-view topdown 중심 보드 한 장으로 만든다. 단일 에셋은 넉넉한 여백을 둔 독립 이미지 한 장으로 만든다. 에셋 멀티뷰 요청은 정사각형 2×2 시트 한 장으로 만들며 순서는 정면(왼쪽 위), 왼쪽(오른쪽 위), 오른쪽(왼쪽 아래), 뒷면(오른쪽 아래)이다. 에셋 멀티뷰에는 구분선, 설명 글, 그림자, 추가 사물을 넣지 않는다.
5. 생성 이미지는 프로젝트 에셋 폴더에 저장한다. 사용자가 명시적으로 교체를 요청하지 않으면 기존 파일을 보존한다. 내용을 알아볼 수 있는 한글 파일명을 사용하고 멀티뷰 원본 시트도 보관한다.
6. 에셋 멀티뷰를 시점별로 정확히 출력할 때는 `scripts/split_multiview.py`로 시트를 같은 크기의 네 구역으로 나눈다. 파일 접미사는 `-front`, `-quarterview-left`, `-quarterview-right`, `-behind`를 사용한다. 두 측면 시점에는 `quarterview-left`와 `quarterview-right`를 사용해 완전한 좌·우 정투영 시점과 구분한다. 배경 원화 보드는 균등 4분할하지 않는다.
7. 생성 이미지 한 장 이상과 분할했다면 대표 분할 결과를 눈으로 확인한다. 배경 원화는 주 시점·1인칭 뷰·소품 개별 컷의 누락과 배치 일치를 확인한다. 잘린 위치가 어긋나거나 시점이 누락되면 원본을 다시 생성하거나 수정한 뒤 완료를 알린다.

## 배경 원화 기본 구성

배경·실내·공간 원화는 사용자가 다른 형식을 명시하지 않으면 다음 세 요소를 한 장에 담은 가로형 보드로 생성한다. 다른 버전 요청에도 이 구성을 유지한다.

- **주 시점 — quarter-view topdown:** 위에서 비스듬히 내려다보는 3/4 시점이 보드에서 가장 큰 영역을 차지한다. 수직 탑뷰가 아니라 바닥 배치와 벽·가구 높이를 함께 읽는 시점이다. 실내는 지붕·천장과 시야를 가리는 전면 벽을 걷어 낸 컷어웨이로 전체 공간을 보여 준다.
- **보조 시점 — 1인칭 뷰 한 장:** 옆 영역에 사람 눈높이에서 본 같은 공간을 배치한다. 주 시점과 출입구·창·가구·소품 위치, 비율, 재질, 조명을 맞춘다.
- **소품 목록 — 주요 소품의 개별 컷:** 하단에 공간에서 사용한 가구와 생활 소품을 분리해 나열한다. 작은 소품은 용도별로 묶되 각각의 형태를 알아볼 수 있게 한다. 공간에 없는 소품을 목록을 채우려고 추가하지 않는다.

구성 참고가 필요하면 `art/concepts/요사채/요사채-원화-topdown.png`를 직접 확인한다. 이 참고의 주 시점·소품 배치 방식을 따르되, 보조 1인칭 뷰는 기본 한 장으로 만든다. 요사채의 가구나 장식 자체를 다른 공간에 복사하지 않는다.

프로젝트의 실사에 가까운 재질 표현을 유지한다. 보드 바탕은 참고처럼 어두운 중성색으로 두고, 각 컷의 여백으로 구분하며 설명 글·번호·워터마크를 넣지 않는다. 실내 조명과 공간을 보여 주는 배경 원화에 단품용 흰 배경·무그림자 조건을 적용하지 않는다. 사용자가 1인칭 한 장 등 별도 구성을 명시하면 해당 요청을 우선한다.

## `/generate-asset` 사용 규칙

`/generate-asset`는 위 작업 순서를 실행하라는 요청으로 취급한다. 프롬프트 작성에 그치지 않고 에셋 제작 지침을 확인한 뒤 이미지를 생성하고 프로젝트 폴더에 저장하며 정확한 출력 경로를 알린다. 카메라나 변형 개수처럼 빠진 선택이 결과를 크게 바꾸는 경우에만 짧게 확인한다. 그 외에는 확정된 프로젝트 기본값을 사용한다.

## 단일 에셋·에셋 멀티뷰 프롬프트 조건

배경 원화는 위 보드 구성을 프롬프트에 명시한다. 단일 에셋·에셋 멀티뷰는 해당하는 경우 다음 조건을 포함한다.

- 독립된 게임 에셋, 중앙 배치, 온전한 실루엣, 넉넉한 흰 여백.
- 고정된 재질 표현: 저채도 오래된 목재, 먹회색 도기 기와, 은은한 세월의 흔적, 절제된 마모.
- 고정된 카메라와 배치: 정면 정투영 또는 요청된 멀티뷰 구역. 원근이 임의로 달라지지 않게 한다.
- 글자, 워터마크, 테두리, 장면 배경, 인물, 식생, 무관한 소품을 넣지 않는다.
- 참고 에셋의 비율, 목재 결구, 기와의 반복 간격, 장식 문양을 유지한다.

변형은 요청된 구성 요소나 시점만 바꾼다. 스타일, 크기, 조명, 배경을 임의로 변경하지 않는다.
