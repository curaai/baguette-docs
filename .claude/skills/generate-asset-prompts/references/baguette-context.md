# Baguette에서 사용하는 근거와 경로

Baguette 문서 저장소에서 에셋 프롬프트를 작성할 때만 사용한다. 이 자료는 로컬 문서 탐색과 저장 관례를 설명하며, 현재 아트 방향을 복사해 보관하지 않는다.

## 근거 찾기

- 저장소 루트 `README.md`와 해당 폴더 목차에서 필요한 문서를 찾는다. 공통 승인·질문·기록 규칙은 `AGENTS.md`를 따른다.
- 아트 방향이 필요한 작업은 `foundation/README.md`에서 `foundation/art-direction.md`의 현재 상태와 해당 내용을 확인한다. 승인된 범위만 반영하며 미결인 스타일을 확정하지 않는다.
- 공간·소품·인물 설정은 요청에 맞는 `planning/`, `narrative/`, `art/concepts/`의 목차에서 찾는다. 특정 사찰·계절·팔레트를 모든 요청의 기본값으로 삼지 않는다.
- 사용자 첨부나 지정 이미지부터 확인한다. 추가 레퍼런스가 필요하면 `art/style-board/`, `art/concepts/`, `art/reference-image-board/` 중 관련 자료만 본다. 폴더에 있다는 이유만으로 승인된 디자인으로 취급하지 않는다.
- 관련 진행 중 태스크를 이어가는 요청이면 `TaskNotes/README.md`와 해당 태스크에서 승인 범위와 재개 정보를 확인한다. 프롬프트 작성만으로 새 태스크를 만들지 않는다.

## 저장

- 이 저장소의 루트가 문서 폴더다. 여기에 `Docs/` 접두사를 다시 만들지 않는다.
- `assets/{에셋명} 프롬프트/`와 `원화_테스트/`는 항상 존재하는 필수 경로가 아니다. 사용자 지정 위치를 우선하고, 지정이 없으면 관련 목차와 실제 폴더에서 저장 관례를 확인한다. 관례도 없으면 경로를 확인하며 본문을 먼저 준비한다.
- 새 문서의 항목은 해당 README 표에 반영한다. 이미 저장을 승인한 범위에서는 저장 직전 재승인을 추가하지 않는다.
