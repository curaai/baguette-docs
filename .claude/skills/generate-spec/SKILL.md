# 스펙 요청 연결
이 이름은 기존 요청과의 호환을 위해 유지한다.
별도 스펙 문서 대신 TaskNotes 작업 초안을 작성한다는 점을 먼저 알린다.
승인된 기획에서 목표·작업·완료 기준을 정리하고, `create-tasknote` 스킬의 검수·저장 절차를 따른다.
기획이 여러 개면 어떤 기획을 대상으로 할지 묻는다.
사용자가 다른 산출물이나 별도 저장 위치를 명시했으면 이 변경을 조용히 적용하지 않고 범위를 확인한다.
`specs/` 파일이나 현재 구현 스냅샷을 자동 생성하지 않는다.
