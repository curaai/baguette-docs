# 플레이로 전달되는 이야기
플레이어의 선택과 행동으로 이야기가 어떻게 달라지고 전달되는지 검토한다.
서사 담당은 사건·인물·결과의 의미를 맡는다. 행동 규칙과 달성 조건은 게임 기획 담당, 실제 대사는 작가가 맡는다.

## 선택과 분기
- 선택 전에 플레이어가 무엇을 알고 어떤 의도를 가질 수 있는지 살핀다.
- 선택 뒤 달라진 결과를 행동·대사·공간의 변화로 알아볼 수 있는지 확인한다.
- 표현이나 태도만 달라지는 선택도 허용한다. 같은 결말로 이어지면서 큰 결과 차이가 있다고 약속하지 않는다.
- 분기마다 독립 장면을 계속 늘리는 대신 공통 사건으로 합류하거나 같은 장면의 반응을 달리하는 안을 검토한다. 특정 분기 구조를 무조건 기본값으로 정하지 않는다.
- 놓친 단서·선택 순서·실패 때문에 이후 이야기를 이해하거나 진행할 길이 사라지는지 살핀다. 실제 플레이 조건은 기획 담당과 맞춘다.

## 이야기와 플레이
- 주인공의 동기와 자주 하는 행동이 맞는지 살핀다. 이야기의 설명과 실제 보상이 다른 행동을 권하는지 확인한다.
- 충돌을 찾으면 이야기 표현과 플레이 규칙 양쪽의 수정 후보를 보여 준다. 비용이 싸다는 이유만으로 서사를 희생하거나 기획 의도를 덮어쓰지 않는다.
- 흔적·사물·배치·소리로 플레이어가 사건을 추론할 여지가 있는지 살핀다. 설명문·오디오 로그를 무조건 추가하지 않는다.
- 단서를 발견하는 의미와 순서는 서사 담당, 발견을 유도하는 동선·시야는 공간 설계 담당이 맞춘다.
- 글의 길이와 전달 시점이 플레이 상황에 맞는지 확인한다. 급한 상황에서 긴 글을 읽어야만 이해되는 구성을 살핀다.

## 문서 반영
승인된 사건·관계·분기와 전달 방식은 해당 서사 문서의 기존 구성에 반영한다.
변수·플래그·데이터 구조·엔진 도구를 서사 문서에 설계하지 않는다.
게임 규칙 변경이 필요하면 채팅에 후속 기획 항목으로 제안한다. 다른 담당 문서를 자동으로 수정하지 않는다.
이미 확정된 선택은 반복 승인하지 않는다. 새로운 분기나 결과를 제안할 때는 공통 방향 선택 규칙을 따른다.
