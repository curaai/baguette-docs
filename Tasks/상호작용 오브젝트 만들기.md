**목표**  
오전 단서 등 집어·살펴볼 오브젝트가 짧게 반응하고, 모으면 다음 구간으로 넘길 수 있게 한다. [[foundation/prototype]]

## 작업

- **공통 컴포넌트**: 트리거 반경 → 프롬프트 표시 → 확인 입력 1회 → `Collected` → 프롬프트 소멸·메시 비활성(또는 빈 자리)
- **단서 3종** (같은 컴포넌트, id만 다름)
  - **A** — 마당/탑 근처. 예: 튀어나온 돌·이상한 흔적
  - **B** — 대웅전 안 더미. 예: 신문 조각
  - **C** — 명부전 문 앞. 예: 젖은 종이·위패 조각 (문은 안 염)
- **피드백**: 세 단서 모두 동일 방식 하나 — 화면 아래 혼잣말 1줄 **또는** 짧은 UI 텍스트. 예: “여기에 뭔가 있다.” / “신문인가…” / “가까이 가지 말라는 건가.”
- **진행도**: `collectedCount` / 비트마스크. 이미 수집한 id는 입력 무시
- **완료 이벤트**: `collectedCount == 3`일 때 **한 번만** `ProtoSlot.Afternoon` 전환 요청 ([[게임 시간·해·시간대 연출]])
- **디버그**: 키로 단서 강제 수집·카운트 리셋

## 완료 기준

- A/B/C를 아무 순서로 3개 모으면 오후로만 넘어감
- 같은 단서 재획득·완료 이벤트 중복 없음
- 요사채·명부전 실내로 들어가지 않고 C까지 가능
