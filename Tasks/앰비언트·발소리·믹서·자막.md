**목표**  
앰비언트 소리를 **네 규칙 플래그 조합**(재생 종류 · 시작/끝 · 다시 나기 · 겹침/앞세우기)으로 재생되게 한다. 정본: [[planning/systems/ambient-sound]]

## 시스템 동작 (구현할 것)

- **재생 종류**: 계속 / 걸을 때 / 한 번 / 가끔 — 소리마다 하나 선택
- **시작·끝**: 소리마다 독립 (예: 존 입장·퇴장, 걷기 시작·정지, 고요 직후, 상태 변화)
- **다시 나기**: 바로 / 쿨다운 / 구간 내 1회 — 소리마다 독립
- **겹침·앞세우기**: 함께 / 내가 앞(다른 소리 줄임) / 내가 뒤·대기 — 소리마다 독립
- **조합 검증**: 위 네 칸이 서로 자동 고정되지 않고 섞일 수 있을 것

## V0로 확인할 조합 예시

- 계속 + 존 체류 + 쉬지 않음 + 뒤 → 룸톤
- 걸을 때 + 걷기 + 걸음마다 + 함께(가깝게) → 발소리
- 한 번 + 고요 후 + 구간 1회 + 앞 → 사아아악/스팅류

## 완료 기준

- 서로 다른 조합의 소리 3종이 동시에/연속으로 규칙대로 나고 멈춤
- “한 번/가끔”이 쿨다운·1회 규칙 없이 스팸되지 않음
- 앞세우기 소리가 날 때 뒤 소리(룸톤)가 밀리는 것이 들림

## 범위 밖

- 추격 거리/상태 연동 위협음 → [[추격 내비·등장·위협 오디오]]
