**목표**  
프로토타입 구간·단서·스폰을 저장·불러와 반복 검증을 쉽게 한다. [[foundation/prototype]]

## 작업

- **세이브 페이로드** (로컬 1슬롯, 덮어쓰기)
  - `slotId`: Entry | Morning | Afternoon | Night | End
  - `clues`: A/B/C bool 3개
  - `playerPos` / `playerYaw` (선택 — 없으면 슬롯 기본 스폰)
- **Save**: 현재 슬롯·단서·(선택) 위치 기록. 디버그 키 예: F5
- **Load**: 페이로드 읽기 → 슬롯 적용([[게임 시간·해·시간대 연출]]) → 단서 오브젝트 상태 동기화([[상호작용 오브젝트 만들기]]) → 스폰 또는 저장 좌표([[스폰 지점 만들기]]). 디버그 키 예: F9
- **새 게임**: 슬롯 Entry, 단서 false, Entry 스폰
- **실패**: 파일 없음/깨짐 → 새 게임과 동일 + 로그

## 완료 기준

- 단서 2개·Afternoon에서 저장 → 에디터 재진입 → Load → 단서 2개·Afternoon·해당 스폰
- Load 후 이미 수집한 단서 재픽업 불가
- F5/F9(또는 동등)로 UI 없이 반복 가능
