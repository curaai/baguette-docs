**목표**  
숲길 오프닝의 혼잣말과, 탑 앞 스님 첫 대화(선택·되돌아가기 포함)를 Yarn Spinner로 재생한다.
정본: [[narrative/opening-mountain-path]] · [[foundation/init]] (어둠 속의 폭우 ~ 첫 만남 대화까지)

## 시스템 동작 (구현할 것)

- **Yarn 기반**: Opening용 Yarn Project + `.yarn` (혼잣말 노드 · 스님 첫 대화 노드)
- **Presenter**: LinePresenter + Text Animator (타입라이터). Classic RPG / Snaaake는 레퍼런스만
- **혼잣말**: 진행 지점 트리거 → 하단 1줄 재생 → 확인으로 진행·스킵 → 조작 잠금/해제
- **스님 대화**: 상호작용 1회 → 제안 대사 → **선택지 루프** → 확정 선택 시에만 종료
- **자막 on/off**: 옵션 훅만

## V0 샘플 (정본 문구)

**혼잣말**
- “길을 잃었다. 우선 비를 피할 곳을 찾아야 한다.”
- “절…? 다행이군.”

**스님 첫 대화**
- 스님: 비가 쉽게 멈출 것 같지 않다 / 산길이 복잡하고 비 많은 계절엔 밖에 나가지 않는 편이 좋다 / 갤 때까지 머물러도 좋다 / 요사채 방 한 칸을 내주겠다
- **선택지**
  - “감사히 머무르겠습니다.” → 합류(종료): 날이 어두우니 어서 가서 쉬어라
  - “폐를 끼치는 건 아닌지…” → 스님 짧은 안심 대사 → **바로 위 선택지로 되돌아감** (확정할 때까지 반복 가능)

## 완료 기준

- 숲길에서 혼잣말 2종이 지정 타이밍에 재생된다
- “폐를…”을 고르면 안심 대사 후 선택지가 다시 나오고, “머무르겠습니다”를 고르면 대화가 종료된다
- 되돌아가기를 여러 번 해도 끊기거나 잠금이 풀리지 않으며, 종료 후에만 조작이 풀린다
