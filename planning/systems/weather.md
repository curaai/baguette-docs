# 날씨

## 오버뷰

사찰 밖 하늘과 공기는 날씨에 따라 달라진다.
날씨는 맑음, 흐림, 비 세 가지다.
비는 약하게 내리는 것과 세게 쏟아지는 것을 같은 날씨 안에서 강도로 나눈다.
각 날씨는 하늘, 구름, 안개, 빗방울, 소리, 빛, 화면 보정을 따로 켜고 끄거나 조절한다.
실내는 날씨 비주얼을 쓰지 않는다.

## 의도

절에 머무는 며칠이 같은 하늘로만 보이지 않게 한다.
맑은 낮, 눌린 흐림, 쏟아지는 비가 번갈아 쌓여 공포와 완화의 대비를 만든다.
날씨가 바뀌기 전까지는 비가 그치지 않고 계속 내린다.
날씨가 바뀔 때 하늘과 소리가 끊기지 않고 이어져야 한다.

## 날씨별 연출

날씨마다 아래 항목을 켜거나 끄고, 수치를 바꿀 수 있어야 한다.
항목 이름은 공통이고, 종류마다 쓰는 방식만 다르다.

### 맑음

| 항목 | 하는 일 |
|------|---------|
| 하늘 | 맑은 하늘 배경을 켠다. 어두운 톤은 쓰지 않는다. |
| 구름 | 끈다. 얇은 고층 구름만 올릴 수 있다. |
| 안개 | 끈다. |
| 빗방울 | 끈다. |
| 소리 | 바람이 거의 없는 고요한 공기. 빗소리는 없다. |
| 빛 | 밝고 선명하게. 그림자 경계가 분명하다. |
| 화면 보정 | 채도와 대비를 올려 건조하고 맑은 느낌을 준다. |

### 흐림

| 항목 | 하는 일 |
|------|---------|
| 하늘 | 눌린 회색 하늘 배경을 켠다. 맑음보다 어둡다. |
| 구름 | 두꺼운 구름층을 켠다. 하늘을 거의 가린다. 밀도와 높이를 조절할 수 있다. |
| 안개 | 옅은 안개를 켠다. 먼 능선과 숲 실루엣을 살짝 흐린다. |
| 빗방울 | 끈다. |
| 소리 | 낮은 바람과 눌린 공기감. 빗소리는 없다. |
| 빛 | 전체적으로 어둡고 부드럽게. 그림자가 옅어진다. |
| 화면 보정 | 채도를 줄이고 대비를 낮춰 무겁고 답답한 느낌을 준다. |

### 비

| 항목 | 하는 일 |
|------|---------|
| 하늘 | 폭우색에 가까운 어두운 하늘 배경을 켠다. |
| 구름 | 낮고 두꺼운 먹구름을 켠다. 흐림보다 더 어둡고 낮다. |
| 안개 | 비와 함께 안개를 켠다. 강도에 따라 농도가 달라진다. |
| 빗방울 | 빗방울 파티클을 켠다. 강도에 따라 양, 속도, 크기가 달라진다. 바닥이나 지붕에 튀는 물방울을 더할 수 있다. |
| 소리 | 빗소리를 켠다. 약한 비는 고요하게, 세게 내리는 비는 크고 촘촘하게 들린다. |
| 빛 | 어둡고 차갑게. 빛이 퍼지고 반사가 젖은 느낌으로 약해진다. |
| 화면 보정 | 대비를 낮추고 채도를 줄인다. 세게 내릴 때는 시야 가장자리가 더 어두워질 수 있다. |

#### 비 강도

같은 비 안에서 두 단계를 바꿀 수 있다.

| | 약한 비 | 세게 내리는 비 |
|--|---------|----------------|
| 빗방울 | 적고 가늘게 | 많고 굵게, 튀는 물방울 추가 |
| 안개 | 옅게 | 짙게, 가까운 물체도 흐려짐 |
| 소리 | 작고 간격 있게 | 크고 촘촘하게 |
| 화면 보정 | 약한 어둡기 | 더 강한 어둡기와 가장자리 눌림 |

## 실내와 실외

실외에서는 하늘, 구름, 안개, 빗방울, 날씨 소리가 모두 보이고 들린다.
실내에서는 위 비주얼을 쓰지 않는다.
실내에서 밖 소리를 들을지는 따로 정할 수 있다.

## 전환

날씨가 바뀔 때 하늘, 구름, 안개, 빗방울, 소리, 빛, 화면 보정이 서서히 바뀐다.
끄는 항목은 사라지기 전에 줄이고, 켜는 항목은 서서히 올린다.
비 강도만 바뀔 때는 하늘과 구름은 그대로 두고 빗방울, 안개, 소리, 화면 보정만 조절한다.

## 필요한 기능

- **날씨 상태** — 지금 맑음, 흐림, 비 중 무엇인지, 비라면 어느 강도인지 유지한다.
- **하늘 배경** — 종류마다 다른 하늘을 켜고 끈다.
- **구름층** — 구름을 켜고 끄고, 밀도와 높이를 바꾼다.
- **안개** — 안개를 켜고 끄고, 농도를 바꾼다.
- **빗방울** — 빗방울과 튀는 물방울을 켜고 끄고, 양과 속도를 바꾼다.
- **날씨 소리** — 종류와 비 강도에 맞는 소리를 깔고, 전환할 때 자연스럽게 바꾼다.
- **날씨 빛** — 종류에 맞는 밝기와 색을 더하거나 빼고, 전환할 때 이어준다.
- **날씨 화면 보정** — 종류에 맞는 채도·대비·어둡기를 더하거나 빼고, 전환할 때 이어준다.
- **비 강도** — 같은 비 안에서 약한 비와 세게 내리는 비를 바꾼다.
- **날씨 전환** — 종류가 바뀔 때 항목마다 켜기·끄기·블렌드를 맞춘다.
- **실외 연출** — 실외에서만 날씨 비주얼을 보여 준다.
