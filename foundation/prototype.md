# 프로토타입 — 공간·공포 하이라이트 검증

정식 스토리(3일·엔딩)와 **별개**로 돌리는 짧은 플레이 루프다.  
절 꾸미기·배경·공포 피크만 먼저 검증하고, 통과 후 앞뒤를 정식 전개에 맞춘다.

정식 3일차 비트는 `narrative/day-3.md`·`foundation/init.md` 정본. 아래는 **프로토타입 전용 전개**다.

## 목적

1. **절을 어떻게 꾸밀지** 고민하고 결정한다.
2. **배경을 꾸며** 공간·분위기 가독성을 본다.
3. **공포의 대상이 나와 심장이 콩닥콩닥하는 하이라이트**까지 가는지 검증한다.

## 프로토타입 전개 (한눈에)

비 맞은 채 절에 들어선다. 그 직후부터 아래만 이어서 플레이한다.

| 순서 | 구간 | 한 줄 |
|------|------|--------|
| 0 | **진입** | 폭우 속 **일주문**으로 들어와 마당에 선다 |
| 1 | **오전** | 절 안을 돌며 단서를 모은다 |
| 2 | **오후** | 탑을 돌다 실루엣이 스친다 |
| 3 | **밤** | 검은 실루엣들이 쫓아온다 → 하이라이트 |
| 4 | **끝** | 짧은 페이드아웃. 엔딩·분기 없음 |

---

## 0. 진입

1. 페이드인. 빗소리·숨소리. 절 **일주문** 안쪽(또는 문 직후 마당).
2. 짧은 혼잣말 정도로 “비를 피했다 / 여긴 절인가”만 둔다. (대사 폴리시 불필요)
3. 목표 표시: **절을 살펴보라** (또는 동등한 짧은 안내).
4. 스님·강아지는 없거나 멀리 스텁. 말을 걸 필요 없음.

**검증:** 첫 시야에서 마당·탑·건물 실루엣이 읽히는가. 비·조명·배경이 톤을 잡는가.

---

## 1. 오전 — 절 안에서 단서 찾기

비는 약해졌거나 가랑비. 낮 조명. 자유롭게 절터를 돈다.

### 진입 규칙

- **실내로 들어가는 건물은 대웅전뿐이다.**
- 요사채·명부전 등은 **밖·문 앞·마당**만 본다. 실내 진입 없음(문 잠금·콜라이더 OK).

### 목표

- 지정된 **단서 N개**(권장 3개)를 찾아 상호작용한다.
- 단서를 다 모으면 오후로 넘어간다. (강제 타이머 없음)

### 공간·단서 배치 (프로토타입용)

장소는 정식 스토리와 달라도 된다. **공간 꾸밈을 보려고** 쓰는 배치다. 단서는 위 진입 규칙 안에 둔다.

| 단서 | 위치 (안) | 상호작용 결과 |
|------|-----------|----------------|
| A | 마당 / 탑 근처 (야외) | 이상한 흔적·물건. “여기에 뭔가 있다” 인지 |
| B | **대웅전 안** (유일한 실내) | 신문·편지·쌓인 물건 등. 짧은 텍스트 1~2줄 |
| C | 명부전 **문 앞** (야외, 실내 금지) | 가지 말라는 느낌 / 젖은 종이·위패 조각 등 |

- 빈 프랍 상호작용은 최소화. **단서만 뚜렷**하게.

### 흐름

1. 마당에서 동선 파악 (탑·대웅전·요사채·명부전 **외관**).
2. 단서 A → B → C 순서는 자유. 실내는 대웅전만.
3. 단서마다 짧은 피드백(혼잣말·UI·사운드).
4. N개 완료 → “탑 쪽으로 가 보라” 등 오후 유도.

**검증:** 꾸며 둔 공간이 “의미 있는 탐색”으로 읽히는가. 동선이 헛돌지 않는가.

---

## 2. 오후 — 탑 돌이 이벤트

하늘이 흐리거나 비가 다시 잦아든 느낌. 목표는 **탑을 돌며 기도(또는 걷기)**.

### 흐름

1. 탑 주변 진입 → “탑을 돌아라 / 기도하라” 상호작용 가능.
2. **돌이 3회**(또는 기도 상호작용 3번). 매 회마다 연출이 한 단계 세진다.

| 회차 | 연출 |
|------|------|
| 1 | 소리가 먹먹해짐. 화면 가장 흐려짐 |
| 2 | 한 번 암전했다가 밝아짐. 가장자리가 더 어두워짐 |
| 3 | 다시 암전 후, **주변시·주변에 검은 실루엣**이 잔뜩. 천천히 다가옴 |

3. 플레이어가 **마우스를 흔들거나** 짧은 탈출 입력으로 “깨어남”.
4. 실루엣은 사라짐. 어느새 해가 기운 듯(조명만 저녁으로).
5. “오늘은 여기까지 / 방으로” 정도로 밤 구간으로 넘김. (요사채 침대 상호작용 또는 자동 페이드)

**검증:** 실루엣 예고가 “불안 → 잠깐의 공포”로 쌓이는가. 탑·마당 배경이 이 장면에 어울리는가.

---

## 3. 밤 — 검은 실루엣 추격 (하이라이트)

폭우·어두운 조명. 프로토타입의 **심장이 콩닥콩닥하는 지점**.

### 흐름

1. 검정 화면 + 빗소리(또는 불길한 큐). 밤으로 깨어남.
2. 마당(또는 지정 스폰)에 나오면 **검은 실루엣**이 시야 가장자리·멀리에 보임.
3. 곧 **여러 실루엣이 쫓아오기 시작**.
4. 플레이어는 절터 안에서 **도망·숨기·경로 찾기** (프로토타입은 단순해도 됨).
   - 예: 마당 → 건물 사이 → **일주문** / 요사채 / 안전 지점까지.
5. 시야가 나쁘면 손전등·짧은 카메라 플래시 등으로 **순간 시야만** 확보해도 됨. (없어도 추격만 되면 OK)
6. 안전 지점 도달 또는 일정 시간 생존 → 추격 종료.

### 연출 우선순위

- “나왔다”가 먼저 보이고
- “쫓긴다”가 몸으로 느껴지고
- “긴장(심박)”이 남는 것

대사·위패·스님 깨우기·법구는 **넣지 않는다.** 추격 하이라이트만.

**검증:** 공포의 대상이 나와 하이라이트까지 가는가. 배경·조명·비가 추격을 죽이지 않는가.

---

## 4. 끝

1. 짧은 암전 + “프로토타입 끝” 수준의 텍스트(또는 로고).
2. 타이틀/재시작으로 돌아가면 충분.

---

## 가정·범위

- 이 루프는 정식 **3일차 재현이 아니다.** 검증용 압축 전개다.
- 스님·강아지·카메라 본편·법구·엔딩 분기는 없거나 최소 스텁.
- 플레이는 짧게. 밀도·공포 피크 확인이 우선.

## 성공 기준

- 절터(대웅전·요사채·명부전·마당·탑)가 **한 장면에 읽히는** 레이아웃·장식이 있다.
- 배경(산·담·나무·비·조명)이 플레이를 방해하지 않고 톤을 잡는다.
- 밤 추격에서 **“나왔다 → 쫓긴다 → 긴장”**이 체감된다.
- 쓸데없는 동선·빈 상호작용 없이 진입→오전→오후→밤이 이어진다.

## 이번엔 하지 않음

- 오프닝 산길·1~2일차 일과·정식 3일차 전체
- 봉인/탈출 엔딩 본편
- 풀 스토리·대사 폴리시
- 최종 에셋·밸런스
