# 용어집 — 불교·사찰

이 프로젝트에서 쓰는 **불교·한국 사찰** 관련 말. 사전 전체가 아니라, 공간·연출·카피에 나오는 말을 맞추기 위한 표다.  
게임 안에서의 쓰임이 일반 해설과 다르면 **우리 용법**에 적는다.

## 공간·건물

| 용어 | 뜻 | 우리 용법 |
|------|-----|-----------|
| **사찰 / 절** | 승려가 수행·거주하는 불교 사원 | ○○사. 산 중턱의 단촐한 직사각 절터 |
| **대웅전** | 본존 부처를 모시는 본당 | 세 건물 중 가장 큼. 불상·기도. 프로토타입에서 유일한 실내 진입 |
| **명부전** | 지장보살·명부(저승) 신앙과 관련된 전각. 위패를 모시는 경우가 많음 | 위패 봉안당. 흉악범 영혼을 모은 비밀의 축. 마당보다 높은 단, 가장 어둡고 낡음 |
| **요사채** | 스님·손님의 숙소 건물 | 스님과 플레이어 숙소. 마당과 같은 높이 |
| **마당** | 건물 사이 열린 뜰 | 일과·석탑·십자 돌길. 주 개방면은 하늘 |
| **석탑** | 돌로 쌓은 탑. 사리·공양 등의 상징 | 마당 중앙. 돌 삐져나옴·법구 은닉 등 단서·엔딩 축 |
| **참배로** | 절로 들어가는 예배·참배용 길 | 산길 50~100m, 구불구불, 표식(석등·이정 돌)만 |
| **일주문** | 절 경내로 들어서는 첫 문. 기둥 열이 한 줄로 읽히는 형태 | 예전 문서의 **절 입구·남쪽 문**과 동일 축. 참배로 끝·절터 진입. **사천왕**을 둔다 |
| **남쪽 문** | (구 배치 명칭) | **일주문**으로 통일. 새 문서에는 쓰지 않음 |
| **석축·담장** | 돌로 쌓은 축대·담 | 절터 플레이·시야 경계 1순위 |
| **석등** | 돌로 만든 등 | 참배로 표식. 절터 프랍과 종류를 섞지 않음 |

## 수호·상

| 용어 | 뜻 | 우리 용법 |
|------|-----|-----------|
| **사천왕** | 사방(東西南北)을 지키는 네 명의 천왕 | **일주문**에 배치. 통과 시 공포 1(무서운 얼굴·지잉) |
| **금강역사** | 절을 지키는 역사(力士) 한 쌍 | **이 프로젝트에서는 쓰지 않음.** 일주문 수호는 사천왕 |
| **불상 / 부처상** | 부처·보살을 형상화한 상 | 대웅전 본존. 위압·실루엣 |
| **지장보살** | 지옥·중생 구제의 보살. 명부전과 자주 연결 | 명부전 설정 배경. 화면 필수 노출은 문서에 따를 것 |
| **위패** | 죽은 이의 이름·위상을 적은 패 | 명부전에 가득. 흉악범 이름 = 클라이맥스 단서 |

## 의례·소품·수행

| 용어 | 뜻 | 우리 용법 |
|------|-----|-----------|
| **염불** | 부처·경전의 이름을 외는 수행 | 대웅전 기도 분위기(소리·불안) |
| **목탁** | 염불·독경 때 두드리는 나무 타악기 | 대웅전 기도 사운드 축 |
| **불단 / 제단** | 불상 앞·아래의 단과 받침 | 대웅전 본존 앞. 향로·공양·촛대의 자리 |
| **공양** | 부처·승가에 올리는 공물·행위 | 대웅전 단 위 소량 그릇·상. 일과·일상의 겉옷 톤 |
| **법구** | 불사·의례에 쓰는 기구·성물 | 봉인 엔딩용 오브젝트(석탑에서 회수). 형태는 PD 미결 가능 |
| **단청** | 목조건물에 올리는 단청 채색 | 바랜 포인트만. 실사 톤에서 과채도 금지 |
| **기와** | 지붕 기와 | 실사 재질 언어 |
| **향** | 향을 피우는 공양 | 대웅전 겉 감각. 속 레이어에서는 습기 냄새 등으로 어긋날 수 있음 |

## 개념·존재 (세계 톤)

| 용어 | 뜻 | 우리 용법 |
|------|-----|-----------|
| **명부** | 저승·사후 심판의 세계관 | 명부전 이름·음습한 톤의 근거 |
| **원혼** | 풀리지 못한 원한을 품은 영혼 | 위패가 깨지며 각성하는 위협 |
| **삿되다** | 바르지 않음. 정법에서 벗어남 | “삿된 것들의 영혼을 모은 사찰” — 설정 한 줄 |
| **아수라장** | 혼란·쟁투의 현장(아수라에서 온 말) | 원혼 각성 후 절터 상태. 봉인으로 진정 |
| **봉인** | 억누르거나 가둠 | 엔딩 분기 — 스님과 함께 진정 |
| **참배** | 절에 찾아 예를 올림 | 참배로·일과 톤. 기자는 위장상 머무는 손님 |

## 쓰지 않거나 주의할 말

- **관광 사찰·포스터 카피** 톤의 “성지 순례” 과장 — 이 게임은 고립·제보·특종 프레임.
- **세미 스타일라이즈드 / 파스텔 판타지 사찰** — 아트 디렉션상 배제. 실사에 가까운 톤.
- **절 입구 / 남쪽 문** — 구호. 새 문서·카피는 **일주문**으로 쓴다.
- **일주문에 금강역사** — 쓰지 않음. 수호는 **사천왕**.
